# 图像编辑提示词模板

将以下字段替换为本次真实输入；不要把未替换的花括号传给图像工具。原照片和风格参考图还须作为独立图片输入传入，不能只写文件名。

```text
任务：将内容参考照片重绘为户外插画贴纸。

内容参考：{source_image}
风格参考：{style_reference}
主体类型：{subject_type}
必须保留：{preserve_features}
背景处理：{background_mode}
精确文字：{exact_text_or_leave_blank}
输出外形：{die_cut_or_postcard}
输出尺寸：{supported_output_size}

保留内容参考的主体姿势、朝向、人数、装备和可辨认特征。
如果有手部，严格保持原照片的左右手关系和手掌朝向。
风格参考仅用于学习造型、线条、配色与纸感，不复制其中的主体。

使用清晰墨线、有限平涂色块、轻微丝网印刷感和纸张颗粒。
配色参考图集中的森林绿、橙色、暖白和山蓝色；天空与远山的蓝色面积按内容照片调整。
在主体外添加均匀暖白模切边，四周预留透明空间。
完整保留主体和裁边，避免厚重三维渲染和明显烘焙投影。

输出单张独立贴纸，真正透明背景；不要绘制棋盘格、网页或展示样机。
不复制参考图集里的登顶人物、跑者群像、山谷步道或日出云海，也不复制灰色展示背景、投影和英文标题。
不增加未要求的人物、标志、装饰文字；不可辨认的文字留空。
```
