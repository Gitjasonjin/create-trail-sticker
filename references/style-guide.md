# RaceMemoir 户外插画贴纸风格规范

## 视觉语言

- 配色参考图集中的深森林绿、鲜橙色、暖白和山蓝色。`#153D31` 与 `#FF621D` 是可用的起点；天空与远山可使用较大面积的冷蓝色，按原照片内容调整。
- 使用近黑色、带少量手绘起伏的墨线，以及层次明确的平涂色块。山脊、岩石、树林可保留细节，但缩小显示时主体轮廓仍须清楚。
- 主体内部加入轻微纸张颗粒与丝网印刷感。避免写实高光、金属镜面效果和厚重三维渲染。
- 主体外添加均匀暖白模切边；默认不烘焙明显投影。白边和主体不得被画布裁断，四周保留真实透明留白。

## 对象处理

- **人物：**保持人数、动作、朝向、身体比例、解剖意义上的左右手关系和手掌朝向；保留背包、登山杖、鞋帽等可识别装备，清理无关背景。
- **奖牌：**保留主要轮廓、山形或赛事图案和绶带关系。将金属质感简化为平面印刷色块。看不清的赛事字样不要猜测。
- **号码布：**号码必须准确。文字密集或生成工具无法可靠呈现时，留出干净区域，后续用可控排版工具补上。
- **风景：**保留主要山脊、道路、地标与前后空间关系；优先选择明信片或纸片外形。

## 参考图的用途

`assets/style-reference.png` 是用户确认的四宫格贴纸图集：登顶人物、跑者群像、山谷步道和日出云海。它仅用于学习墨线、配色、纸感、图形简化方式和不规则暖白模切边，不是待转换照片，也不意味着要把图集里的全部物件画进结果。灰色底板和外投影属于展示方式，不要烘焙进独立贴纸；底部英文标题仅是参考图内容，用户未要求时不要照搬或添加文字。
